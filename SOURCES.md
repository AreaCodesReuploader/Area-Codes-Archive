# Reconstruction Sources

This file documents the surviving sources used to reconstruct, verify, and preserve **“Area Codes // dreamwastaken.”**

The complete Wattpad reupload was reconstructed personally by the repository maintainer before the current repository organization work began.

## Reconstruction Overview

The story was recovered and verified using a combination of surviving materials rather than a single complete source.

These materials included:

* Cached versions of original Wattpad pages
* Locally saved Wattpad HTML files
* Companion `_files` folders
* Original Wattpad chapter URLs
* Archive.today captures
* Bing cache screenshots
* YouTube chapter readings
* Personal notes and backups
* The final chapters briefly reposted by the original author before being removed again
* The completed Wattpad reupload itself

Not every chapter relied on every source.

A chapter-by-chapter source ledger should be added as the surviving materials are organized.

## Source Confidence

Use the following confidence labels where useful:

* **Confirmed** — directly supported by a surviving original or author repost
* **Strongly supported** — supported by multiple independent surviving sources
* **Probable** — supported by one credible but incomplete source
* **Uncertain** — partially reconstructed or based on incomplete evidence
* **Unidentified** — source exists but has not yet been matched to a chapter

## Preservation Principle

The project should distinguish clearly between:

* Original surviving material
* Reconstructed text
* Reupload formatting
* Later editorial cleanup
* Uncertain or inferred content

Differences should be documented rather than silently collapsed into a single supposedly definitive version.
